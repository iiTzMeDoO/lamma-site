# لَمّة | Lamma

## الترتيب
- `index.html` الصفحة الرئيسية (لازم تضل هون) و `home/` ملفاتها
- `wheels/` العجلات كلها (الصفحات + الكود)
- `battle/` المعركة: الألوان، الساحة، TNT، المحارب (الصفحات + الكود + الستايل)
- `games/<اللعبة>/` كل لعبة بفولدر لحالها: تمثيل charades، كلمات سرية codenames، أسرع واحد fast، خمّن الرقم guess، مين الأرجح likely، أسئلة trivia، سلسلة كلمات chain
- `account/` صفحة تسجيل الدخول
- `shared/` الأشياء المشتركة بين كل الصفحات: css، js، fonts، img
- `vercel.json` بيحوّل الروابط القديمة (مثل /wheel-pick.html) للجديدة، مشان روابط OBS القديمة تضل شغالة

## Vercel
ارفع محتوى الفولدر بالريبو مباشرة، وما في build ولا إعدادات.
